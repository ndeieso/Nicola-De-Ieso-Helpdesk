2.	Trobleshooting examples
CASE 1 - Computer is running slow
Checks: Take info about when the problem began; check Task Manager to see open applications and services; restart the computer.
Next step/resolution: after checking for apps and services opened, check for other issues such as hardware issues to continue diagnosing the problem.
CASE 2 - Cannot connect to a network
Checks: Check for wired and wired connection; check other devices; check for configuration issues.
Next step/resolution: if the above didn't fix the problem, check for possible issues with network/Wi-Fi adapter or even problems with the telecommunications provider.
CASE 3 - Issue with Outlook mails
Checks: Check for local sync issues by checking both the desktop app and the web version. Check also for Internet connectivity.
Next step/resolution: Check the local cache in case the issue is only on the desktop app; in case the issue is also on the web version, check for possible issues with the online account. If all the steps don't work, escalate the issue to the email provider (Microsoft, Google, etc.)
CASE 4 - Printer not working
Checks: Check if the printer is on and checks also the cables; check for paper; checks for pending jobs into the Windows printer interface. Next step/resolution: If these basics steps don’t help, check for possible driver issues.
When doing a ticket, report all the steps and information but never password or other sensible data.

2.	Exemples de dépannage
CASE 1 – An ordinateur il marche lentement
Contrôles : Prends des informations sur quand le problème est commencé ; contrôle le gestionnaire des tâches pour voir les applications et les services ouverts ; redémarrer l’ordinateur.
Prochaines étapes / résolution : Après contrôle des applications et des services ouverts, contrôler pour autres problèmes comme problèmes de matériels pour continuer à diagnostiquer le problème.
CASE 2 – Impossibilité de se connecter à un réseau
Contrôles : Contrôler les connections filaires et sans fil ; contrôler autres appareils ; contrôler pour des problèmes de configuration.
Prochaines étapes : si les étapes au-dessus n’ont pas résolu le problème, contrôler pour problèmes avec le matériel du réseau filaire et/ou sans fils ou même des problèmes dépendant du provider des télécommunications.
CASE 3 – Problèmes avec les courriels Microsoft Outlook
Contrôles : Contrôler pour des problèmes de synchronisation en contrôlant à la fois l’application de bureau Microsoft Outlook et la version web. Contrôle aussi la connectivité réseau.
Prochaines étapes / Résolution : Contrôler la cache locale si le problème est présent seulement dans l’application de bureau ; si le problème est présent aussi dans la version Internet, contrôler pour des problèmes avec le compte Internet. Si toutes les étapes ne fonctionnent pas, escalader le problème au le fournisseur du courriel (Microsoft, Google, etc.
CASE 4 – L’imprimante ne fonctionne pas
Contrôles : Contrôler si l’imprimante est allumée et contrôle aussi les câbles ; contrôle le chargement du papier ; contrôle les travails en attente dans la gestion d’imprimante Windows.
Prochaines étapes / résolution : Si ces contrôles basiques n’ont pas aidés, contrôle pour des probables problèmes de pilote.
Quand on fait un ticket, rapporter toutes les étapes et informations mais jamais mettre des mots de passe ou autres informations sensibles.
